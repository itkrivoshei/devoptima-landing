# DevOptima Landing Page

Responsive landing page built with React, TypeScript, Tailwind CSS and Vite.

## Live Demo

https://itkrivoshei.github.io/devoptima-landing/

## Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- GitHub Pages

## Features

- Responsive layout
- Reusable React components
- Tailwind-based styling
- Static production build
- GitHub Pages deployment

## Project Structure

```bash
src/
├── components/
├── App.tsx
├── main.tsx
└── index.css
```

## Run Locally

```bash
git clone https://github.com/itkrivoshei/devoptima-landing.git
cd devoptima-landing
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Preview

```bash
npm run preview
```
